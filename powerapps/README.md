# Power Apps

This directory contains the `apptelemppsol` Dataverse solution source. It
currently includes the `app-telem-pp-weather-flow` cloud flow, the
`crf6e_apptelemweather` table, and the `crf6e_apptelemppmodapp` model-driven app.
The weather flow is Power Apps-triggered, fetches today's forecast for London,
and writes a row to the Dataverse weather table.

There is no Canvas app in the solution yet. Canvas app source is generated by
Power Apps Studio under a `canvas/` folder when a Canvas app is added to the
solution, published, and synced to Git. Create the Canvas app in Studio and add
the existing weather flow as a data source before editing or committing its
source here.

## Application Insights tracing

Configure the Canvas app's Application Insights connection string on the app
object in Power Apps Studio, then save and publish the app. `Trace()` events are
sent to Application Insights when the published app runs; Studio preview does
not send these events.

Wrap the flow call in the button's `OnSelect` behavior formula with start,
success, and failure traces. For example, after adding the flow to the app,
replace `<weather-flow-reference>` with the flow name Studio inserts:

```powerfx
Set(varTraceRunId, Text(GUID()));
Trace(
    "weather-flow.started",
    TraceSeverity.Information,
    { clientRunId: varTraceRunId, flowName: "app-telem-pp-weather-flow" }
);
IfError(
    '<weather-flow-reference>'.Run();
    Trace(
        "weather-flow.succeeded",
        TraceSeverity.Information,
        { clientRunId: varTraceRunId, flowName: "app-telem-pp-weather-flow" }
    );
    Notify("Weather flow completed.", NotificationType.Success),
    Trace(
        "weather-flow.failed",
        TraceSeverity.Error,
        { clientRunId: varTraceRunId, flowName: "app-telem-pp-weather-flow" }
    );
    Notify("Weather flow failed. Check the flow run and app telemetry.", NotificationType.Error)
)
```

`clientRunId` correlates the traces emitted by this app invocation. The current
flow accepts no inputs, so this identifier is not passed into the flow. Keep
personal or sensitive data out of trace custom properties.
